# Problem Format

## 1. Problem

Each coding problem contains:

- problem_id
- title
- description
- difficulty
- topics
- constraints
- input_format
- output_format
- examples
- starter_code
- supported_languages
- expected_time_complexity
- expected_space_complexity
- hints
- editorial
- test_cases

## 2. Difficulty

Supported difficulty levels:

- Easy
- Medium
- Hard

## 3. DSA Patterns

Supported patterns include:

- Arrays
- Strings
- Hashing
- Two Pointers
- Sliding Window
- Stack
- Queue
- Linked List
- Binary Tree
- BST
- Heap
- Graph
- BFS
- DFS
- Dynamic Programming
- Greedy
- Backtracking

## 4. Test Cases

Each test case contains:

- test_case_id
- input
- expected_output
- visibility

Visibility can be:

- public
- hidden

Hidden test inputs and expected outputs must never be returned to the student.

## 5. Output Comparison

Supported comparison modes:

- exact
- whitespace_normalized

## 6. Verdicts

The judge supports:

- ACCEPTED
- WRONG_ANSWER
- COMPILATION_ERROR
- RUNTIME_ERROR
- TIME_LIMIT_EXCEEDED
- MEMORY_LIMIT_EXCEEDED
- EXECUTION_ERROR
- INTERNAL_ERROR

## 7. AI Tutor

The AI tutor can provide:

- error explanation
- conceptual hint
- stronger hint
- approach explanation
- optimized solution explanation
- code explanation
- complexity analysis
- optimization suggestions

AI does not determine whether a submission is correct.

The deterministic judge is always responsible for the final verdict.
